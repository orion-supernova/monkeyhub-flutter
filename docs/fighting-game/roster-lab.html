Jungle Fist · roster lab · 2026-11-05

THE STARTERS

Four fighters, one from each family: KAI, MOJO, TANK and NYX. Pick a fighter, then a move or the combo loop. Every one is drawn in code in all three looks, with their own special moves and effects. Slow-mo shows the frames.

Everything above is drawn with the Canvas 2D API in this file. The Flutter version uses the same approach through CustomPainter / Flame. Pixel style = the cartoon rig rendered at half resolution, snapped to a palette and outlined per pixel.
